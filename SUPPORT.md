# Support

## Questions and help

Use GitHub Discussions if they are enabled. Otherwise, open an issue using the question template.

For quick feedback, the maintainer also accepts public messages on X: [@adidshaft](https://x.com/adidshaft).

## Bugs

Open a bug report with:

- command used
- expected behavior
- actual behavior
- Node.js version
- OS
- whether the run used subtitles, AI, `--dry-run`, `--debug`, or `--non-interactive`

If a command references a private video or file path, redact it while keeping the shape of the command clear.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Maintenance expectations

This is an open-source project maintained around practical creator workflows. Issues with clear reproduction steps, focused scope, and tests or sample outputs are easiest to prioritize.
