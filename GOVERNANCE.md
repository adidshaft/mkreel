# Governance

`mkreel` is currently maintained by [@adidshaft](https://github.com/adidshaft).

## Decision making

The maintainer makes final decisions for roadmap, releases, issue priority, and pull request acceptance. The project favors:

- reliable local CLI behavior
- clear validation and deterministic outputs
- creator-friendly defaults
- optional AI assistance that cannot bypass core validation
- small, reviewable changes

## Becoming a regular contributor

Regular contributors are people who consistently submit useful issues, reviews, documentation, tests, or code. Maintainer permissions may be added over time when a contributor has shown good judgment and project context.

## Releases

Releases are created from `main`. Publishing to npm is handled through the repository's publish workflow after tests, typecheck, and build complete.
